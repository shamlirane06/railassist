RailAssist

Navigating the Station Made Simple

RailAssist is a web application designed to help passengers who are unfamiliar with a railway station.

It helps users find platforms, facilities, accessibility options, assistance and emergency support inside the station through a simple and accessible interface.

The project is currently a working prototype focused on demonstrating the core passenger experience.


 Inspiration

Railway stations can be confusing for passengers who are visiting them for the first time.

Finding the correct platform, toilet, lift, exit or help desk can become difficult, especially for first-time passengers, tourists, elderly passengers and people with accessibility needs.

This inspired us to build "RailAssist" — a simple station assistance platform that brings navigation, assistance, accessibility and emergency features together in one place.



 What It Does

RailAssist provides a centralized interface for important station-related tasks.

 Destination Search
Users can search for:
- Platforms
- Toilets
- Lifts
- Exits
- Help desks
- Other station facilities

 Indoor Station Map
Users can view an interactive digital map of the station and identify:
- Platforms
- Exits
- Toilets
- Lifts
- Stairs
- Escalators
- Help points
- Current location

 Passenger Assistance
Users can request different types of assistance:
- Directions
- Elderly assistance
- Wheelchair assistance
- Lost item assistance
- Porter/Luggage assistance
- Other assistance

 Accessibility
RailAssist includes accessibility-focused features such as:
- Wheelchair assistance
- Elderly assistance
- Visual assistance
- Hearing assistance
- Large text
- High contrast

 Emergency Support
The SOS section provides options for:
- Medical emergency
- Unsafe situation
- Someone needs help
- Lost or confused passengers

The current emergency workflow is a prototype simulation and is not connected to live emergency services.
